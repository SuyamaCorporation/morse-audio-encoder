# Morse Code Audio Encoder

Type any message to see and hear its Morse code, or paste Morse to decode it back to text, with adjustable WPM speed and visual symbol highlighting.

## Features
- Full International Morse Code: A–Z, 0–9, and common punctuation
- Visual dot-and-dash display with per-symbol highlight synced to audio playback
- Web Audio API 700 Hz sine-wave tones with smooth attack/release envelopes
- WPM slider (5–30) dynamically adjusts unit duration (1200/WPM ms)
- Decode mode: paste dots, dashes, and slashes to get plain text back
- Built-in reference table for all encoded characters

## Usage
Type text in the encode panel and click Play to hear it. Drag the WPM slider to change speed. Switch to the Morse → Text tab and type Morse code (use space between symbols, slash for word breaks) to decode. Press Stop to halt playback at any time.
